# ShopNest Store Power BI Capstone

## 📊 Project Overview

ShopNest Store Power BI Capstone is a retail analytics project developed using Microsoft Power BI to analyze sales performance, delivery efficiency, customer preferences, product ratings, regional sales, seasonal trends, and revenue.

## 🎯 Key Analyses

- Top 10 Product Categories by Total Price
- Delayed Orders by Product Category
- Monthly Delayed vs On-Time Orders
- Payment Method Analysis
- Top 10 & Bottom 10 Product Ratings
- State-wise Sales Analysis
- Quarterly Sales Trends
- Yearly Revenue Analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization
- Business Intelligence
